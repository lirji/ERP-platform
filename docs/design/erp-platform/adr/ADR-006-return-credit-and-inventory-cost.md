# ADR-006 — 退货红字、待退款与库存成本

状态：实施并通过 P7 本地真实数据库验证。

用户 2026-09-22 选择：退货生成独立红字及待退款，保留原现金事实。
采购和销售按实际收发货行退货，原行持久化入账金额/币种快照；累计比例差使整行退货精确带走金额尾差。销售回库批次显式指定，回库成本取原出库流水，财务金额取原销售金额。

原往来金额、收付款及核销流水不重写。fin_credit_adjustment 负数记录为权威红字，原往来 credited_amount 为同事务累计投影；待退款及已退独立记录。先锁原往来单再写红字/退款，与原收付款锁顺序一致。来源唯一键、金额上界条件更新、数据库检查共同兜底。
信用查询端口 releasedCredit 计算红字加未被红字覆盖的有效核销；原 netSettled 内部方法更名以体现语义扩展。原现金额度与新增核销受冲红后净额限制，历史核销保留，可通过原反核销机制补偿。

成本按现有六维库存桶移动加权，本位币六位精度；清仓吸收尾差。未知历史成本不补猜，新旧写入共存时数量变化先失效成本，新版同事务恢复正确值。盘点使用持久冻结及数据库保护，调拨成本保留在途事实。

替代方案：直接减原应收/应付会破坏已付款/核销约束与审计，因此不采用；禁止已结算退货被用户否决。未引入外部支付、跨公司调拨或工作流基础设施。
