# ADR-007 — 报表使用可恢复快照投影

阶段 P9 已选定：查询 rpt_*，重建从权威模块导出端口读取，遵守既有模块依赖和数据所有权。

本期先提供明确刷新时间的快照，不增加消息基础设施。每类报表独立快照；不是跨五类报表的统一财务结账时点。分批扫描/写入/游标提交，前后指纹不一致的候选不发布，原发布指针保持可用。源数据稳定时，全扫描结果可重复；持续写入环境可能反复 STALE，应选择空闲窗口。未来若需要持续实时看板，再以已明确的版本事件推进增量投影。

指纹依据受控写入的不变量：库存桶 version 单调递增、交易行数量/金额在正向提交后不可变且 returned_qty 单调递增、财务单 version 随现金/核销/红字增加。物理删除、直接改写数据库不在在线业务接口中；运维修数必须重新构建，不承诺发现对冲式人工篡改。

重建每步至多1000行，同任务行锁保护重复执行；数据和游标原子提交。旧快照可按 snapshotId 稳定翻页。取消不撤销任何业务事实，只使候选失效。默认保留历史快照；管理员确认无读者后可用 purgeStep 分批回收非当前终态快照，不能清理当前或构建中快照。

账龄从往来创建日期起算，不冒充合同逾期；交易按原单日期累计净退货口径；金额未知显式标出未知行数。当前不新增生产 HTTP 入口。
