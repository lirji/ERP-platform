# P7.3 退货与财务红字契约

用户决策：独立红字及待退款，保留原收付款事实。

退货以实际收货/出库行作为来源，累计数量不能超过该来源行数量；销售退货必须明确回库批次。每次退货独立单据、命令幂等键、审批和过账；禁止修改原收发货流水。
金额使用来源行当次已过账金额的累计比例差，最终整行退回带走舍入尾差。来源行需保存 posted_amount；旧单缺少可靠的金额快照时明确拒绝退货财务过账，不从现价猜算。

财务按原应收/应付锁串行接受退货事件，生成非正红字事实（零价退货为零），累计红字绝对值不超过原金额。原金额、实收付、原核销均保留；credited_amount 是独立事实的累计投影。
新增退款义务 = max(0, 实收付 + 累计红字绝对值 - 原金额) - 已产生退款义务。
AR 义务为退客户款，AP 义务为待供应商退款；本地完成退款记录只是人工确认到账/付出的账务事实，不调用支付网关。
退款必须带命令幂等键、币种及操作人，累计完成不超过对应义务；每次完成保留单独记录。
冲红后不得再超额收付款或新增核销；历史已核销金额可以高于冲红后净额，不篡改历史事实。
信用释放 = 红字绝对值 + min(有效核销净额, 原金额 - 红字绝对值)，避免退货与原核销重复释放信用。
事件至少一次投递，来源财务单尚未到达时失败重试，不吞消息。历史缺失财务事实仍需另行对账补齐。
