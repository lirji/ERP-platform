# P7 库存成本与逆向业务契约

## P7.1 成本

沿用库存六维桶（租户/公司/仓库/库位/SKU/批次）作为移动加权计价单元，单一租户本位币；本期不跨批次合并成本。
PostingRequest 新增可空 inboundValue（本次入库总成本，6 位小数，非负）；旧构造器兼容，空值表示成本未知，绝非零价。出库不得指定入库成本。
采购以订单单价乘收货数量计算入库成本；成本账保留 6 位，财务单据金额仍按既有 4 位累计舍入。
出库成本=出库前总成本×出库数量÷出库前在库数量，HALF_UP 至 6 位；清仓带走全部尾差。
余额 inventory_value 和流水 signed_value 同一事务；桶锁保护数量及加权成本快照。
历史非空桶缺少成本时保持 NULL，部分出库仍未知；清仓后余额归零，后续已知入库恢复计价。历史流水不补猜金额。
未知值不可用于宣称成本或利润完整。来源键幂等沿用 P3。

## 后续逆向业务已确认规则

采购/销售退货必须新建单据，原收付款及核销事实不改写。财务生成独立红字调整及待退款记录；销售退货显式指定回库批次。具体实现和验收在对应切片补齐。

兼容旧版数量写入：V101 触发器在数量变化时失效成本，新版在同一事务补齐；旧版继续写入会使成本显式未知，不会残留虚假均价。

## P7.2 调拨、盘点与调整

StockOperationService 使用单桶作业（每单一个 SKU/批次）；调拨限定同租户同公司同 SKU 同批次、目标桶不同，整单调出及整单接收。跨公司调拨不在本契约内。
编号规则 STOCK 必须配置。单据沿用标准 DRAFT→SUBMITTED→APPROVING→APPROVED→PROCESSING→FINISHED；审批实例校验租户和单据归属，每次状态变化记录审计及版本。
调拨调出减少源桶 onHand、增加源桶 inTransit；接收减少源桶 inTransit、增加目标桶 onHand，两个写入同事务。PROCESSING 的作业成本是独立在途价值，不包含在任一仓在库成本中；接收直接携带调出成本。已调出不允许取消，接收失败保留原在途事实。
盘点 beginCount 原子冻结单桶、保存快照；recordCount 只在草稿录入非负实盘数。普通过账拒绝被冻结桶，数据库触发器同时阻止旧版数量写入绕过冻结。执行在持桶锁的同一事务解冻、差异过账并完成，失败回滚冻结。取消可释放冻结；预占仍须满足原约束，盘亏不足可用量时拒绝过账，需先处理预占。
调整必须选择 DAMAGE/FOUND/CORRECTION 原因码、填写说明、记录创建人并经过审批；正向可传成本，反向按库存均价出库。盘盈使用冻结快照均价；空桶或未知成本保持未知。
这些为内部应用服务；不代表已提供生产 HTTP 权限入口。
