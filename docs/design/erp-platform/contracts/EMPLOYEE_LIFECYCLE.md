# 员工生命周期（P11 原计划缺口补齐）

内部服务 `EmployeeService` 提供入职、关联用户、离职；没有新增 HTTP 端点。调用者继续承担已认证的操作人和权限边界。

工号租户内唯一；同工号同组织同名称的在职入职重试返回原记录，内容冲突或离职后重新使用拒绝。公司必须为启用 COMPANY，部门为该公司路径下启用 DEPT。关联账户必须同租户/公司/部门且启用，一个账户只能关联一个员工；已经关联其他账户时不能改绑。

状态仅 `ACTIVE → LEFT`。员工行锁、版本条件更新、关联账户禁用处于同一事务；重复离职无额外副作用。离职保留用户、角色及历史单据，后续 `AccessContextAssembler` 拒绝禁用用户。已有在途请求不承诺自动撤销。生命周期成功审计在提交后记录。

V120 增加表及租户复合外键，不修改历史迁移。验证见 `EmployeeLifecycleIT`（离职/幂等/跨租户/组织归属拒绝）与全量真实 PostgreSQL 回归。
